# Loja Umbrel da Cardosoft

Loja da comunidade do umbrelOS, só com o manifesto do Portal Cardosoft: nome, ícone e `docker-compose.yml`.
Não tem código nem dados. A imagem do portal é criada no próprio Umbrel e nunca vai para um registo público.

Instruções: `UMBREL.md`, na pasta do projeto do portal.
