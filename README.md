# Loja Umbrel do Portal

Loja da comunidade do umbrelOS, só com o manifesto do Portal Gestão: nome, ícone e `docker-compose.yml`.
Não tem código nem dados. A imagem do portal é criada no próprio Umbrel e nunca vai para um registo público.

Instruções: `MIGRAR-UMBREL.md`, na pasta do projeto do portal.
